# Product Purpose & Strategy

## Product Summary
Oppy OS is an evidence-driven, high-fidelity Founder Decision Operating System. It functions as a structured command center for founders, venture builders, and product leaders to track and validate early-stage product concepts objectively.

## Problem Statement
Early-stage founders often fall victim to confirmation bias, spending months and thousands of dollars building products that nobody wants. Traditional tracking methods (spreadsheets, general boards) do not enforce systematic evidence gathering, nor do they calculate dynamic priority scores derived from user interviews, preorders, and conversion metrics.

## Target Audience
- **Primary**: Independent Solo Founders & Indie Hackers validating multiple concurrent concepts.
- **Secondary**: Venture Studios, Incubators, and Innovation Labs looking to manage pipeline portfolio concepts objectively.
- **Confidence Rating**: **High**. The user experience and workflow are strictly designed around validation workflows (TTFD, validation speed, pain intensity indices).

## Value Proposition
Oppy OS transforms qualitative founder ideas into structured, prioritizable venture concepts. It dynamically scores each opportunity based on real evidence (evidence score), quantifies risk vectors, automatically provisions outreach and validation assets, and provides actionable, daily strategic briefing directives.

## Verified vs. Inferred Features
- **Verified Features (Fully Implemented)**:
  - Multi-category portfolio directory (Industrial AI, Climate/DeepTech, B2B SaaS, DevTools).
  - Standardized scoring mechanism based on Idea Quick-Test Index (IQI) and Killer Risk analysis.
  - Automatic asset provisioning (custom landing page markdown, cold outreach scripts, interview templates).
  - Bring-Your-Own-Key (BYOK) settings interface supporting Google Gemini, Groq, and OpenRouter.
  - Interactive validation tracker updating scores in real-time based on interviews, visits, signups, and revenues.
- **Inferred Features**:
  - Live landing page staging & rendering engine (currently offers high-quality markdown artifacts for visual deployment).
  - Live CRM connection to pipeline sources (currently uses a local REST backend with offline database backups).
